# QCM

Site de QCM interactif pour réviser les cours de Holberton School. Application web statique, contenue dans un seul fichier HTML, qui propose une série de questions à choix multiples avec correction immédiate.

## Contenu

- `qcm-holberton.html` : l'application complète (questions, logique de correction et style)

## Utilisation

Ouvrir le fichier `qcm-holberton.html` dans un navigateur, ou le servir en local :

```bash
python3 -m http.server 8000
```

Puis ouvrir http://localhost:8000/qcm-holberton.html
